# e-plantShopping

## Paradise Nursery Shopping Cart Application

Paradise Nursery is a React shopping cart application for an online plant store.

The application allows users to browse different categories of houseplants, add plants to a shopping cart, change product quantities, remove items, and view the total cost of their purchase.

This project was developed using React, Redux Toolkit, JavaScript, HTML, and CSS as part of the final project for the React course.
